# test_clicker

Консольный кликер на C++, учебный пет-проект.

## Что умеет
- `1` — клик, копит монеты
- `2` — магазин: показывает список улучшений и покупает выбранное
- `0` — выход

Улучшения увеличивают силу клика.

## Структура
- `Resource` — количество ресурса, `add` и `spend`
- `Upgrade` — название, цена и бонус улучшения
- `Game` — правила игры: клик, счёт, покупка улучшений
- `main()` — только ввод и вызовы `Game`

Ввод остаётся в `main()`, чтобы консоль можно было заменить на GUI.

## Сборка
Visual Studio: открыть `test_clicker.slnx` и запустить («Локальный отладчик Windows»).

## Планы
Сохранение в файл, пассивный доход, GUI.
